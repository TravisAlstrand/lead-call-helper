# Lead Call Helper

A single-page script for health-insurance lead calls. Pick a lead type and the matching script appears. Fill in details during the call, then copy or download the notes as plain text.

There is no build step. Open `index.html` in a browser, or serve the folder locally.

## What it keeps

Your name is saved in the browser so it fills in on the next visit. The client name, lead type, and form answers are not saved. Copy Results puts the notes on the clipboard. Download Results saves a `.txt` file.
